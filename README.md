## Идея компании

Мы анализируем данные по играм и ищем "мёртвые". Изучаем, что послужило причиной, как быстро игры умирают, как это зависит от жанра, рейтинга, сборов игр и других факторов. Потом планируется эти данные продавать компаниям, занимающимися разработкой игр.
